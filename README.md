# SovereignGate

SovereignGate is a digital sovereignty assurance tool for European companies. It matches a software inventory against a curated jurisdiction dataset, computes a transparent weighted score, writes a live AI assurance report, and produces a dated certificate.

## Product scope

- Live sovereignty scoring from matched reference data
- Category and tool-level jurisdiction findings
- Plain-language AI report covering three priority migrations
- Exportable Digital Sovereignty Assurance Certificate
- Published scoring methodology and privacy policy

The output is decision-support, not legal advice or an accredited regulatory certification.

## Development

This application uses TanStack Start, React, TypeScript, Tailwind CSS, and a managed PostgreSQL backend.

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.
